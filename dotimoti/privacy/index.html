1. 적용 범위와 기본 원칙

com.dotimoti.app.next · 모티도티는 계정 기반 미션·루틴·개인 기록과 선택형 SNS 게시를 제공합니다. 공동미션과 기부는 포함하지 않습니다.

미션과 개인 기록은 계정의 서버 저장소에 보관해요. 게시하기 전에는 공개되지 않아요.

비밀번호를 타인에게 알려주지 마세요. 불법·괴롭힘·권리침해 콘텐츠를 금지해요. 콘텐츠나 사용자를 신고하면 담당자가 검토해요. 차단하면 양쪽 모두 메시지·댓글·응원을 보낼 수 없어요.

계정의 비공개 기록

미션과 개인 기록은 계정의 서버 저장소에 보관해요. 게시하기 전에는 공개되지 않아요.

  • 미션·수행루틴: 이름, 설명, 표지, 목표 횟수, 마감일, 루틴 단계·시간·반복 및 수행 설정.
  • 수행기록: 시작·종료 시각, 경과 시간, 완료 상태, 반복 카운터, 메모, 사진과 편집용 복사본.
  • 피드 첨부: 사진·동영상 원본과 선택 구간, 배치, 어둡기, 음소거, 글자·기록·스티커 등의 편집 정보.
  • 휴대폰 측정: 선택한 기능에 따라 위치 좌표·이동 시각·경로·거리·속도·페이스·고도, 걸음 수·층수 및 반복 횟수.
  • 선택형 건강 데이터: Health Connect에서 가져온 심박수·걸음 수·거리·활동 칼로리·총 칼로리·속도·누적 상승고도, 제공 앱·시간 구간·조회 상태 등 출처와 품질 정보. 기간 평균에는 실제 표본 합계와 표본 수를 함께 보관합니다. 휴대폰 측정값과 출처를 구분해 보관합니다.
  • 도우미와 설정: 알림 시각, NFC 태그 식별값과 미션 연결, 소리·알람·방해금지 설정.
  • 로컬 식별값: 앱 설치 단위의 식별값과 미션·수행기록 식별값. 광고 식별자로 사용하지 않습니다.

3. 위치와 미션 시작 도우미

이동 측정을 켠 수행에서는 경로와 거리를 기록하기 위해 위치를 사용합니다. 수행을 계속하는 동안에는 다른 앱을 보거나 화면을 꺼도 포그라운드 서비스로 측정이 이어질 수 있습니다.

현재 출시 버전은 장소 도착 알림이나 수행 전 백그라운드 위치 감지를 제공하지 않습니다. 시간 알림과 NFC 태그는 연결한 미션 화면을 여는 데 사용합니다.

시간 도우미와 NFC 시작 기능은 미션 편집에서 끌 수 있습니다. 위치 권한은 Android 설정에서 철회할 수 있으며, 철회하면 이동 경로와 거리 측정이 제한됩니다.

4. Health Connect와 웨어러블 데이터

선택한 항목의 수집에 동의하고 권한을 허용한 경우, Health Connect에 이미 저장된 심박수·걸음 수·거리·활동 칼로리·총 칼로리·속도·상승고도를 읽어 수행기록에 연결합니다. 자동기록의 동의·접근 권한과 날짜별 집계 범위는 14절을 따르며, 심박·속도는 전달된 실제 표본의 평균으로 계산합니다. 웨어러블에 직접 연결하거나 Zepp 같은 제공 앱의 계정·비밀번호를 받지 않습니다. 휴대폰 앱이 제공한 데이터도 포함될 수 있어 제공 앱을 표시하며, 모든 값이 워치 측정값임을 보장하지 않습니다.

사용자가 시작한 수행의 건강 데이터는 수행 시작·종료 시각을 기준으로 집계합니다. 해당 시간에 걸쳐 있는 심박·칼로리 기록을 찾기 위해, 권한으로 접근 가능한 수행 시작 이전 기록도 조회할 수 있습니다. 조회 과정에서 수행과 무관한 과거 기록이 반환될 수 있으나, 수행 관련 표본·요약·구간·출처·조회 진단 정보를 선별해 저장하며 과거 건강 기록 전체를 일괄 보관하지 않습니다.

건강 데이터는 읽기 전용으로 사용하며 Health Connect에 쓰거나 원본을 삭제하지 않습니다. 권한 허용만으로 동기화 완료나 데이터 존재가 보장되지는 않습니다. 제공 앱의 동기화 지연·기록 단위에 따라 누락이나 구간 추정이 있을 수 있고, 다시 가져오기를 할 수 있습니다.

이 정보는 활동 기록·기간별 통계·설정한 성공 기준의 판단·개인 확인 및 사용자가 선택한 기록 공유에 사용하며 판매, 광고, 신용평가 등에 사용하지 않습니다. 의료 진단·치료를 위한 기능이 아닙니다. Health Connect 설정에서 데이터 종류별 접근 권한을 철회할 수 있습니다.

5. 사진·동영상과 기타 권한

  • 선택한 동영상은 앱 비공개 저장소로 복사하며 자르기와 기록 합성은 기기에서 처리합니다. 첨부 원본과 편집 정보는 계정에 비공개로 보관합니다. 게시하거나 외부 공유하면 선택한 미디어와 표시할 기록이 전달되며 갤러리 원본은 변경하지 않습니다.
  • 모티도티에서 직접 촬영하거나 켜 둔 자동 촬영으로 찍은 사진은 기록 저장 후 Pictures/모티도티 앨범에도 복사합니다. 앨범에서 가져온 사진은 갤러리에 중복 저장하지 않습니다. 앱의 첨부 사본과 편집 정보는 계정에 비공개로 보관합니다.
  • 알림·진동과 허용한 정확한 알람은 미션 시작 안내와 수행 제어에 사용합니다. 활성 측정과 소리 재생은 화면이 꺼져도 포그라운드 서비스로 이어질 수 있습니다. 현재 앱은 전체화면 알람 권한을 사용하지 않습니다.
  • 카메라·신체 활동 권한은 선택한 촬영과 걸음 측정에 사용합니다. NFC는 직접 연결한 태그를 읽어 미션 화면을 엽니다. 선택형 방해금지 접근은 수행 동안 해당 모드를 조절합니다. Android 설정에서 권한을 철회할 수 있습니다.

6. 내장 공식미션과 업데이트 통신

공식미션 목록·기본 설정·일러스트는 앱에 포함되어 있으며, 목록을 열거나 기본 이미지를 선택하기 위해 서버에 접속하지 않습니다. 새 공식미션은 앱 업데이트로 추가됩니다. 공식미션 조회를 위해 사용자의 미션·수행기록·사진·건강 데이터·계정 토큰을 외부 서버로 보내지 않습니다.

이 개발 빌드는 HTTPS로 새 모티도티 전용 서버의 업데이트를 확인해요. 업데이트를 선택했을 때만 APK를 내려받아 해시·앱 식별자·설치된 앱의 서명을 검증하고 Android 확인 후 설치해요. 요청에는 IP 주소·요청 시각 등 일반 연결 정보가 포함되며 개인 기록이나 계정 인증정보는 보내지 않아요. 기본 공식미션 목록은 오프라인에서도 사용할 수 있어요.

7. 지도와 지형 고도 보정

기록의 지도 배경을 열면 OpenStreetMap 지도 타일 서버에 표시 지역의 타일 요청과 일반 접속 정보가 전달됩니다. 원본 GPS 경로 파일·건강 수치를 지도 타일 서버에 업로드하지는 않지만 타일 식별자로 열람 지역을 추정할 수 있습니다.

각 수행기록의 지도 메뉴에서 ‘지도 숨기기’를 선택하면 그 기록은 경로 모양만 표시하고 지도 타일을 요청하지 않습니다. ‘지도 보기’를 선택하면 지도 배경을 다시 표시합니다. 이 기록별 선택은 저장된 GPS 원본을 삭제하거나 측정을 중단하지 않습니다. 경로 모양만으로도 장소가 추정될 수 있습니다.

GPS와 경로 고도 기록을 켠 수행은 저장 시 지도 기반 고도를 자동 계산합니다. 기존 미보정 기록도 조회 시 자동 보정할 수 있습니다. 기록별 지도 배경 표시와 관계없이 캐시가 없으면 s3.amazonaws.com/elevation-tiles-prod의 Terrarium 지형 타일을 요청합니다. 타일 식별자와 접속 정보가 전달되며 원본 GPS 파일·수행 시각·건강 수치는 보내지 않습니다. 보정 실패 시 원본을 보존하며 다음 조회 시 다시 시도합니다. 지형 고도는 건물 층수나 교량의 실제 높이와 다를 수 있습니다.

개인 기록과 외부 공유

미션과 개인 기록은 계정의 서버 저장소에 보관해요. 게시하기 전에는 공개되지 않아요.

외부 공유·내보내기를 선택하면 고른 앱이나 저장 위치에 정보가 전달됩니다. GPX에는 지도 배경을 숨겼더라도 정확한 좌표와 시각이 포함될 수 있습니다. 받는 사람과 공개 범위를 확인하세요. 이미 공유한 사본은 회수할 수 없습니다.

계정 보관과 삭제

미션과 개인 기록은 계정의 서버 저장소에 보관해요. 게시하기 전에는 공개되지 않아요.

설정 또는 계정 삭제 웹페이지에서 탈퇴를 신청할 수 있어요. 즉시 접근과 게시물 공개가 중단되며 30일 안에 로그인하면 취소돼요. 30일 후 계정·기록·게시물·댓글·응원·대화·첨부자료를 삭제해요. 휴대폰 갤러리 원본은 삭제하지 않아요.

앱을 삭제하거나 기기 앱 데이터를 지워도 계정과 서버 기록은 삭제되지 않습니다. 계정 자료 삭제는 회원 탈퇴를 이용해 주세요. 갤러리 원본·Health Connect 원본·외부 공유 사본은 해당 위치에서 별도로 관리해야 합니다. 기기 사본은 Android 자동 백업을 사용하지 않습니다.

10. 이용자 선택과 보안

필요하지 않은 측정·도우미·자동 가져오기 기능을 끄거나 Android·Health Connect 설정에서 권한을 철회할 수 있습니다. 이미 가져와 보관 중인 데이터는 권한 철회만으로 삭제되지 않으므로 필요하면 해당 기록을 삭제하세요.

앱 전용 저장소와 운영체제 권한으로 접근을 제한하고 온라인 기능에는 HTTPS를 사용합니다. 어떤 저장·전송 방식도 절대적인 보안을 보장하지 않습니다. 기기 잠금, 최신 운영체제, 내보낸 파일·백업 관리가 중요합니다.

개인정보와 건강 데이터를 판매하거나 광고 목적으로 사용하지 않습니다. 아동의 정보에도 같은 보호 원칙을 적용하며, 보호자는 데이터 처리나 삭제와 관련해 아래 문의처로 연락할 수 있습니다.

11. 외부 서비스와 문의 시 제공한 정보

지도는 OpenStreetMap과 Amazon 지형 타일을, 선택형 건강 권한은 Android 서비스를 사용해요. 계정 서버 HTTPS 요청에는 IP 주소와 요청 시각이 포함돼요.

이 방침은 GitHub Pages에 공개하며 방문 시 GitHub가 IP 주소 등 일반 접속 정보를 처리할 수 있습니다. 같은 본문을 앱에 내장해 오프라인에서도 읽을 수 있습니다. 현재 모티도티는 광고·이용 행태 분석 SDK를 포함하지 않습니다.

12. 방침 변경

앱 기능이나 데이터 처리 방식이 바뀌면 이 방침과 시행일을 갱신합니다. 중요한 변경은 앱 또는 스토어 등록정보 등을 통해 안내합니다.

14. 선택형 미션 자동기록과 휴대폰 관찰

자동기록은 동의·필요 권한·미션 활성화가 모두 확인된 뒤 시작합니다. 사용 기록 접근은 기기에서 화면·잠금 이벤트를 처리해 휴대폰의 마지막 사용 시각을 추정하며 수면이나 다른 기기 사용을 측정하지 않습니다. 권한 허용만으로 다른 측정이나 촬영이 시작되지는 않습니다.

하루 걸음수는 미션 시간대의 00시부터 Health Connect에 저장된 합계를 읽으며 동의 이전의 같은 날 걸음도 포함할 수 있습니다. 지난 날짜는 하루 전체 합계를 사용합니다. 지원 기기에서 백그라운드 건강 읽기를 별도 허용하면 주기적으로 갱신하고, 미허용 시 앱을 열어 갱신합니다. 절전·제공 앱 동기화·권한 상태에 따라 갱신이 지연되거나 값이 없을 수 있습니다.

앱에서 자동기록을 중지하거나 Android·Health Connect 설정에서 권한을 철회할 수 있습니다. 기존 기록은 직접 삭제할 때까지 남습니다. 앱 데이터를 초기화하면 다시 동의해야 합니다. 권한 철회만으로 계정 기록이나 Health Connect 원본은 삭제되지 않습니다. 건강·휴대폰 관찰 데이터는 광고에 사용하지 않습니다.

휴대폰 관찰로 산출한 결과는 다른 기록과 함께 계정에 비공개로 보관합니다. 원시 사용 이벤트·앱 패키지명·앱별 사용 내역은 업로드하지 않습니다. 권한 접근과 서버 비공개 보관은 SNS 공개를 의미하지 않습니다.

모티도티 계정

ID · 가입과 계정 복구에 아이디·비밀번호·표시 이름·인증 이메일을 사용합니다. 비밀번호는 서버에서 해시로 처리합니다. 인증 코드는 유효기간이 있으며 비밀번호를 변경하면 모든 기기에서 로그아웃됩니다.

서버는 계정 프로필과 세션 인증 정보를 반환합니다. 접근 토큰은 메모리에만 유지합니다. 암호화한 갱신 인증 정보와 프로필만 앱 전용 저장소에 보관하며 Android 백업과 기록 내보내기 백업에서 제외합니다. 비밀번호는 저장하지 않습니다. 저장한 인증 정보는 해당 서버에 연결됩니다.

미션과 개인 기록은 계정의 서버 저장소에 보관해요. 게시하기 전에는 공개되지 않아요.

설정 또는 계정 삭제 웹페이지에서 탈퇴를 신청할 수 있어요. 즉시 접근과 게시물 공개가 중단되며 30일 안에 로그인하면 취소돼요. 30일 후 계정·기록·게시물·댓글·응원·대화·첨부자료를 삭제해요. 휴대폰 갤러리 원본은 삭제하지 않아요.

16. 선택형 SNS 공유

게시할 때 선택한 사진·편집한 영상·기록카드·본문을 업로드해요. 다른 사람이 미션을 추가할 수 있도록 미션 게시물에는 목표·측정 설정·루틴 구성도 공유돼요. 원본 GPS·건강 샘플·원본 수행기록은 업로드하지 않아요.

일반 게시물은 계정의 전체공개·승인된 응원자 공개 설정을 따라요. SNS 휴식으로 기록을 지우지 않고 게시물을 숨기거나 댓글을 멈출 수 있어요. 캠페인 인증은 공개와 댓글을 유지해요.

기존 제한 게시물을 일괄 공개로 바꾸지 않아요.

공개범위는 기존·새 일반 게시물에 모두 적용돼요. 보관하면 게시물과 개인 피드를 숨기고 반응은 읽기 전용으로 유지해요. 게시 취소는 반응을 지우고 개인 피드로 되돌려요. 이미 내려받거나 공유한 사본은 회수할 수 없어요.

계정별 기기 사본으로 중단된 게시를 중복 없이 재시도해요. 로그아웃하면 계정별로 분리돼요. 게시물을 삭제해도 개인 원본은 남으며 탈퇴 유예기간이 지나면 개인 원본도 삭제해요.

개인 피드와 SNS 게시물은 별도로 편집하며 연결된 버전에 반영할지 선택해요. 측정 원본은 바뀌지 않아요. 공유 미션을 가져오면 내 독립 미션이 만들어져요.

17. 공개 프로필

공개 게시물·사용자·공식미션을 검색해요. 사용자 검색어는 서버로 보내지만 개인 기록에는 저장하지 않아요. 검색이 개인 기록을 게시하지는 않아요.

프로필을 저장하면 표시 이름·한마디·자기소개와 새로 선택한 프로필 사진을 계정 서버로 보냅니다. 다른 사용자에게 프로필 정보로 표시됩니다. 선택한 사진은 크기를 줄이고 원본 위치 메타데이터 없이 다시 인코딩합니다. 취소하면 선택한 사진을 업로드하지 않습니다. 교체·삭제한 프로필 사진도 서버에 남을 수 있으며, 이미지 URL을 아는 사람은 열 수 있습니다.

18. 다이렉트 메시지

DM 내용·사진·참여자 ID는 HTTPS로 서버에 보관하며 종단간 암호화는 아니에요. 사진은 발신자·수신자 확인 후 제공하므로 URL만 알아서는 볼 수 없어요. 사진은 위치 정보를 제거해 재인코딩해요. 대화를 열면 읽음 상태가 갱신돼요.

미전송 DM·사진은 계정·수신자별로 기기에 보관하고 연결되면 중복 없이 전송해요. 대화 지우기·나가기는 내 사본만 숨겨요. FCM은 기기 토큰으로 내용·건강정보 없는 일반 알림을 보내요. 알림 허용은 선택이며 로그아웃하면 이전 계정 알림을 멈춰요.

19. 문의하기

문의와 추가 질문을 보내면 계정 ID, 분류, 제목, 확인한 내용이 계정 서버에 전송돼요. 본인과 권한이 있는 담당자만 대화를 볼 수 있어요. 답변은 문의 내용과 앱 내 알림에서 확인해요. 문의는 SNS 게시물이 아니며 SNS 휴식이나 공개범위 변경으로 공개되지 않아요. 보내지 않은 내용은 메모리에만 보관돼요. 비밀번호나 민감한 건강정보는 적지 마세요.

계정의 비공개 기록

개인 미션·루틴·기록·첨부 사진·영상·경로·건강 데이터는 HTTPS로 계정 DB에 보관해요. 기기 사본이 오프라인 수정을 보호하고 재연결·재실행 후 전송을 재시도해요. 충돌한 버전은 확인 전까지 보존하며 백그라운드 재시도가 진행 중인 측정을 멈추지 않아요. 이전 기기 자료는 가져오지 않아요.
