# DotiDoit Legal Pages

도티두잇(DotiDoit, Android package `com.doti.doit`)의 공개 개인정보처리방침입니다.
운영자: **opensky**. 개인정보 문의: **eonseok.yoon@opensky.co.kr**.

저장소 이름 `dotimoti-legal`은 유지하지만 현재 게시된 방침의 대상은 도티모티가 아니라 **도티두잇**입니다.

## Google Play에 입력할 공개 URL

https://kizwond.github.io/dotimoti-legal/dotidoit/privacy/

GitHub Pages의 `main` / root 배포를 사용합니다. 공식 주소는 `dotidoit/privacy/`입니다. 이전 `dotitimer/privacy/` 주소는 새 주소로 자동 이동하며, 자동 이동을 지원하지 않는 환경을 위한 링크도 제공합니다. 기존 링크 호환성을 위해 이전 경로를 삭제하지 마세요.

## 정책 범위

- 미션·수행루틴·사진·동영상·메모·위치·건강 데이터의 로컬 보관과 사용자 선택에 따른 처리.
- Health Connect의 심박·걸음·거리·활동 및 총 칼로리·속도·누적 상승고도 읽기, 선행 구간 조회와 출처·품질 정보.
- 별도 동의·권한에 따른 자동기록, 지원 기기의 백그라운드 읽기, 하루 걸음수의 해당 날짜 00시 누적 집계.
- 사용 기록 접근으로 처리하는 화면·잠금 이벤트와 휴대폰 미사용 관찰. 실제 수면 측정이나 앱별 사용 내역의 서버 수집이 아닙니다.
- 시간·NFC 도우미, 카메라·알림 및 수행 중 위치 측정 관련 권한. 현재 출시판은 장소 도착
  알림과 수행 전 백그라운드 위치 감지를 제공하지 않습니다.
- 공인미션과 도티 이미지는 앱에 내장하며 앱 업데이트로 추가합니다. Preview 업데이트 통신,
  OpenStreetMap 지도, Amazon S3 지형 타일, 현재 출시판의
  DotiMoti 앱 간 연동 비활성 상태.
- ZIP 백업·기기 백업·공유·삭제의 범위와 이미 외부로 복사된 데이터의 별도 관리.

로컬 우선이라는 이유만으로 Play의 데이터 보안 항목에 모두 ‘수집 없음’이라고 답하지 마세요. 실제 출시 AAB, 포함 SDK, 네트워크 요청, 선택형 공유 및 Google의 정의를 확인해 별도로 작성해야 합니다. 이 문서 갱신만으로 모든 정책 심사를 통과했다는 뜻은 아닙니다.

## 앱 내부와 동기화

한국어·영어 본문 14개 절의 기준 원본은
`doti_doit/app/src/main/java/com/doti/doit/PrivacyPolicyScreen.kt`(1–13절)와
`PrivacyPolicyContent.kt`(14절)입니다. 공개 페이지는 현재 광고 OFF 배포의 안내를 따릅니다. 공개 HTML은 기준 원본을
따르는 배포용 미러입니다. 변경 시 양쪽 본문, 시행일, 연락처를 함께 수정하고 앱 소스 빌드와
공개 HTTP 응답을 확인하세요. `doti_doit/PRIVACY_POLICY.md`와 `privacy.html`은 이 공식 페이지를
안내하는 포인터이며 별도 방침 사본으로 확장하지 않습니다. 웹 갱신은 기존 설치 앱의 내장 문구를
자동 갱신하지 않으며 앱 문구는 다음 빌드에 포함됩니다.

2026-10-27 개정은 기존 로컬 초안의 장소 도착 알림 제거·위치 측정·지도·백업·연동 OFF 정리를
보존하고 자동기록·휴대폰 관찰·당일 누적 걸음수·동의 철회·복원 후 재동의를 보완합니다.
Play에서는 자체 APK 업데이트와 전체화면 알림 권한을 사용하지 않는 점도 구분합니다.

2026-11-02 개정은 공인미션·이미지 앱 내장, 서버형 루틴 링크 가져오기 종료, 선택한 동영상의
기기 내 편집·가공 MP4 공유·원본 전체를 포함하는 ZIP 백업을 반영합니다. 앱의 광고 OFF
한국어·영어 14개 절과 동기화했으며 Preview 1.0.216(373)에 맞춰 7개 언어로 확장했습니다.

## 7개 언어와 재생성

한국어는 위 기본 주소, 나머지는 `en/`, `ja/`, `zh-hans/`, `zh-hant/`, `es/`, `vi/`입니다.
기존 기본 주소의 `#ko`·`#en` 앵커와 `dotitimer/privacy/` 리디렉션은 유지합니다.

`policy/*.json`은 앱의 광고 OFF 14개 절을 동기화한 배포 원본입니다.
한국어·영어는 컴파일된 `privacyPolicySections(code, false)`에서 추출하며 나머지 5개는
앱의 `localization/privacy/*.json`과 같아야 합니다. 수정 후 아래 두 명령을 실행합니다.

```
python3 scripts/build_privacy.py
python3 scripts/build_privacy.py --check
```

앱과 웹의 동영상 원본·편집·MP4 공유·원본 전체 ZIP 백업 설명을 함께 검토하세요.
