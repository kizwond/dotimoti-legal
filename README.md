Static legal pages for DotiMoti apps.

## Public URLs

After GitHub Pages is enabled for `main` / root:

- DotiTimer Privacy Policy: `https://kizwond.github.io/dotimoti-legal/dotitimer/privacy/`

## Google Play Console

For DotiTimer:

- App content > Privacy policy URL: use the DotiTimer Privacy Policy URL above.
- Data safety: keep answers consistent with the policy.
  - DotiTimer Play release does not send routine data, notes, photos, or identifiers to a developer server.
  - Routine data, run history, notes, photos, and settings are stored locally on the user's device.
  - If the user imports DotiTimer records from DotiMoti on the same device, DotiMoti may read local routine-run records through DotiTimer's read-only provider.
