# 도티두잇 방침 설명 보완

2026-11-24. 새 미션 체계와 지도 이미지 기능에 맞춰 기존 처리 범위를 명확하게 설명한다. 수집 항목·수신자·광고 SDK·보관 구조를 추가한 개정이 아니다. 기존 광고 포함 방침 시행일2026-11-10을 유지하고 **설명 보완일2026-11-24**를 별도로 표시했다.

- 2절: 날짜별 목표/통계의 기기 내 계산, 목표/판정 방식 변경 시 성공 횟수 재계산, 원본 실적·수정 이력·사진 보존.
- 8절: 기존 경로를 기기에서 지도 이미지로 만들어 피드에 사용하고, 외부 공유를 선택하면 이미지와 표시한 기록을 선택 앱에 전달. 기존7절 지도 타일 요청 설명은 유지.
- 앱과 공개 페이지를7개 언어로 함께 수정. Android 런타임의 광고 포함15절과 공개 `policy/*.json`을 제목/목록/문단 단위로 대조해 모두 일치함을 확인했다. 문단 순서는 내용 비교에서 정렬해 처리했다.
- 앱별 주소·언어 전환·기존 한국어/영어 앵커·광고 고지·백업/삭제/건강 데이터 설명을 유지한다.
- 모티 `policy/dotimoti/`와 공개 모티 페이지는 변경하지 않는다.

`build_privacy.py --check`, `check_moti_privacy.py` 통과. 전체7개 공개 응답의 반영 여부는 푸시 후 별도로 대조한다. 현재 Play Console 신고를 변경했다거나 새 AAB 검증을 완료했다는 뜻은 아니다.
