# 모티도티 정책 명칭·현재 미션 체계 반영

모티96 실제 앱의20절×7언어 방침을 추출해 공개본을 생성했다. 이름은 모티도티/MotiDoti, 설명 갱신일은2026-11-26이다.

- 계정별 비공개 서버 보관, 오프라인 기기 사본과 재전송, 사용자 선택 SNS 공개·계정/자료 삭제 범위는 유지한다. 두잇의 로컬 보관/광고 방침으로 대체하지 않는다.
- 기한·독립 목표 횟수·선택형 일단위 수행목표, 저장=수행, 입력 데이터의 사용자 정의 이름/형식/단위, 승인 후 시즌 재판정과 피드/게시물 스냅샷 보존을 설명한다.
- 루트 앱 선택·아동 안전·자료 삭제 안내의 오래된 이름도 정리했다. 기존 URL/패키지/복구·삭제 경로와 보관 이력은 유지한다.
- build_moti_privacy.py와 check_moti_privacy.py로7언어 모티/두잇 본문 일치·앱별 주소·JavaScript 없는 탐색을 확인했다. 공개 배포는main 푸시 후 응답으로 재확인한다.
